# Handbook 反馈收集

> 将学习中发现的 Handbook 问题、建议、补充整理到此目录
> 
> 每个反馈一个文件，格式 `FB-编号-简述.md`

## 反馈分类

| 分类 | 说明 | 示例 |
|------|------|------|
| 🐛 **修正** | 错别字、概念错误、链接失效、资料过期 | 第 X 章的概念描述有误 |
| 💡 **补充** | 需要补充的案例、图表、代码示例 | 建议增加 AA 与 Agent 对比图 |
| 🔗 **连接** | 章节之间的关联建议、跨领域链接 | Agent 章节应引用 AA 章节 |
| 🌐 **翻译** | 翻译不准确、术语不一致 | "Vibe Coding"翻译建议统一 |

## 反馈提交渠道

1. **GitHub Issues**：通过本仓库提交
2. **Telegram 社区**：在 AI×Web3 School 社区提出

## 反馈编号规则

- 编号格式：`FB-XXX`（从 `FB-001` 开始递增）
- 提交顺序编流水号

---

### 示例

```
# FB-001 - [修正] Agent 章节中工具调用的描述链接失效

- **分类**：🐛修正
- **来源**：Phase 1 学习
- **Handbook 页面**：https://aiweb3.school/zh/handbook/ai/agent/
- **问题描述**：
  > "结合 MCP 协议实现工具调用" 段落的链接跳转到了 404 页面
- **建议改法**：更新链接到 https://aiweb3.school/zh/handbook/ai/mcp/
- **日期**：2026-05-20
```
